## [0.1.0] - 2026-10-28

First release of the zero-dependency JSON / TOML / MessagePack serialization
library with byte-identical output across five language ports.

### Added

- Canonical value model shared by every port: `null`, `bool`, `int` (i64),
  `uint` (u64), `float` (binary64), `str`, `bytes`, `array`, `table` (sorted
  bytewise, duplicates fail closed), and TOML `datetime` (offset / localdt /
  date / time, raw text preserved).
- JSON codec (RFC 8259): strict parser with `SERDE_JSON_*` diagnostics
  (syntax, UTF-8, depth, trailing, int-range, float-naninf, bytes, datetime),
  canonical compact encoder with bytewise key sorting and shortest-roundtrip
  float rendering (integral floats keep one fractional digit; exponential
  form at `>= 1e+21` / `<= 1e-7`).
- TOML v1.0 codec: full parser (bare/quoted/dotted keys, tables, arrays of
  tables, inline tables, basic/literal/multiline strings, hex/oct/bin
  integers with underscores, datetimes) and canonical serializer
  (scalars, then `[tables]`, then `[[arrays-of-tables]]`).
- MessagePack codec: minimal-length encoding families, float64-only floats,
  canonical quiet NaN, `timestamp` ext (-1) support in the 32/64/96 carriers,
  fail-closed rejection of unknown extension types.
- Shared contract enforcement: 176 deterministic test vectors
  (`vectors/lombokserde-vectors-v1.json`, 122 success + 54 error cases) with
  `vectors/SHA256SUMS`, generated by `vectors/build_vectors.py`; every port
  runs the full set bit-identically in CI.
- Five ports: Rust (crate `lombokserde`, reference implementation),
  TypeScript (npm `lombokserde`, dual ESM + CJS), Python (PyPI `lombokserde`,
  PEP 621), Go (module `github.com/codinglombok/lombokserde/go`), and PHP
  (Packagist `codinglombok/lombokserde`, PSR-4, PHP >= 8.1).
- Stable `[SERDE_<FMT>_<REASON>] message (at byte N)` error display with
  cross-port-identical byte offsets.
- Tooling and CI: `scripts/lombok-doctor.sh` (v3.6 standards checks),
  `scripts/bump_version.sh` (staged bump), `vectors/build_vectors.py`
  (deterministic generator), GitHub Actions `ci.yml` (per-port matrix jobs,
  coverage gates, vector regeneration diff, doctor) and staged release
  workflows (`release.yml`, `release-npm.yml`, `release-crates.yml`,
  `release-pypi.yml`, `dry_run` defaults to `true`).
- Documentation pack v3 under `docs/` (10 public documents, versioned file
  names) plus `README.md` and this changelog.
